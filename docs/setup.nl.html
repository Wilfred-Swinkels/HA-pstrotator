PstRotator voor Home Assistant

De wereldkaart-kaart activeren

Een keer de entiteit aanmaken, daarna de kaart op het dashboard zetten -- via het automatische "Home"-overzicht, of via een eigen dashboard. Beide routes staan hieronder naast elkaar.

Dit is het eindresultaat -- waar deze handleiding naartoe werkt.

Stap 0 -- De azimuth-entiteit aanmaken

Verplicht eerst

De kaart heeft een entiteit nodig om naar te verwijzen. Die ontstaat pas zodra de PstRotator-integratie zelf is ingesteld -- zonder deze stap heeft de kaart straks niets om te besturen.

  1. Ga naar Instellingen -> Apparaten en diensten.

  2. Klik rechtsonder op + Integratie toevoegen.

  3. Zoek naar PstRotator en klik het resultaat aan.

  4. Vul het formulier in: een naam (bijv. "Shack"), het IP-adres van de PC waar PstRotator op draait, de poort (standaard 12000) en het protocol.

  5. Klik op Verzenden. De integratie wordt aangemaakt, en daarmee meteen ook de azimuth-entiteit.

  6. Noteer de entity-ID. Die vind je terug op de integratiekaart, of via Instellingen -> Entiteiten (zoek op "azimuth"). De naam is afhankelijk van wat je bij "naam" invulde -- bijvoorbeeld:

    number.shack_pstrotator_azimuth
Kies een route
ROUTE A

Vanaf het Home-icoon

Het automatisch gegenereerde overzicht in het menu. Moet eerst "overgenomen" worden voor je er een eigen kaart aan kunt toevoegen.

  1. Klik op Home links in het menu.

  2. Klik rechtsboven op het potlood-icoon (Bewerken).

  3. Verschijnt er een melding om het dashboard over te nemen? Bevestig die -- eenmalig, zet het auto-dashboard om naar een bewerkbare versie.

  4. Klik op + Kaart toevoegen.

  5. Zoek naar PstRotator Card en klik 'm aan.

  6. Vul bij Entity de entity-ID uit stap 0 in.Titel en stapgrootte zijn optioneel.

  7. Klik op Opslaan.

  8. Sluit het bewerken af via het potlood-/vinkje-icoon rechtsboven.

ROUTE B

Vanaf een eigen dashboard

Een zelf aangemaakt dashboard (via Instellingen -> Dashboards) is al bewerkbaar -- de "overnemen"-stap vervalt.

  1. Open je eigen dashboard via het menu links.

  2. Klik rechtsboven op het potlood-icoon (Bewerken).

  3. Kies de gewenste view/tab, of maak een nieuwe view aan voor de kaart.

  4. Klik op + Kaart toevoegen.

  5. Zoek naar PstRotator Card en klik 'm aan.

  6. Vul bij Entity de entity-ID uit stap 0 in.Titel en stapgrootte zijn optioneel.

  7. Klik op Opslaan.

  8. Sluit het bewerken af via het potlood-/vinkje-icoon rechtsboven.

Liever YAML? Schakel in de kaart-editor over naar "Bewerk in YAML" en plak:
type: custom:pstrotator-card
entity: number.shack_pstrotator_azimuth
step: 5
